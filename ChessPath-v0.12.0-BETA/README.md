# ChessPath v0.12.0 BETA

Current Chrome Web Store beta source for ChessPath.

## Opening book
- 3,538 named opening lines / variations
- 33,641 theory move-steps
- 7,337 indexed positions
- 1,102 branching points

## Features
- Interactive opening explorer and contextual branch tree
- Opening / ECO recognition
- Move, attack, and defense visualization
- Theory previews
- Local and hosted Friend Play
- Manifest V3 Chrome extension

The repository is private. The complete Chrome Web Store upload package, including the generated opening database files and icons, is stored alongside this source as `ChessPath-v0.12.0-BETA-Chrome-Web-Store.zip`.

Beta feedback is tracked in issue #1.
